# Организатор файлов (Python)

Скрипт наводит порядок в папке: раскладывает файлы по категориям, находит дубликаты, умеет работать в фоне и отменять свои действия. Только стандартная библиотека, Python 3.9+, ничего ставить не нужно.

## Быстрый старт
```
python organizer.py ~/Downloads --dry-run     # посмотреть, что будет сделано
python organizer.py ~/Downloads               # разложить файлы
python organizer.py ~/Downloads --undo        # вернуть всё обратно
```

## Возможности
- Категории: изображения, документы, таблицы, презентации, архивы, видео, аудио, программы, код, остальное
- Дубликаты (по содержимому, а не по имени) уходят в папку «Дубликаты»
- Конфликты имён решаются автоматически: `file (1).txt`
- Не трогает скрытые файлы, недокачанные (`.crdownload`, `.part`, `.tmp`) и только что изменённые
- Журнал перемещений и команда `--undo` для отмены последнего запуска
- Режим наблюдения: `--watch 60` проверяет папку каждую минуту
- Отчёт в Markdown: `--report report.md`

## Параметры
| Параметр | Что делает |
|---|---|
| `--dry-run` | только показывает план, файлы не трогает |
| `--by-date` | внутри категорий создаёт папки по месяцам (`2026-11`) |
| `--min-age N` | пропускает файлы, изменённые менее N секунд назад (по умолчанию 30) |
| `--watch N` | работает постоянно, проверка каждые N секунд |
| `--undo` | отменяет последний запуск |
| `--report файл.md` | сохраняет отчёт |

Свои категории добавляются в словарь `CATEGORIES` в начале `organizer.py`.
